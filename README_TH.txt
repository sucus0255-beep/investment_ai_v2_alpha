Investment AI V2.0 Alpha — Dual Brain Simulator

ฟรี 100% ไม่มี API Key ไม่มีการเชื่อมต่อบัญชีธนาคารหรือซื้อขายจริง

Windows:
1. แตกไฟล์ ZIP
2. เปิด PowerShell ในโฟลเดอร์ investment_ai_v2_alpha
3. รัน py -m http.server 8000
4. เปิด http://localhost:8000

Android (ติดตั้ง PWA แบบไม่ต้องเปิดคอมพิวเตอร์):
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์ไปยัง HTTPS static hosting เช่น GitHub Pages
2. เปิดลิงก์ HTTPS ใน Chrome บน Android
3. เลือกเมนู ติดตั้งแอป หรือ เพิ่มไปยังหน้าจอหลัก
4. หลังโหลดและ cache สำเร็จ ใช้ฟังก์ชันคำนวณแบบออฟไลน์ได้

หมายเหตุ: เปิด index.html โดยตรงแบบ file:// อาจดูหน้าจอและคำนวณได้ แต่ Service Worker/PWA ต้องใช้ HTTPS หรือ localhost
ข้อมูลที่บันทึกไว้เก็บใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น
สมองคู่เป็นกฎจำลอง ไม่ใช่ GPT หรือ Gemini API จริง
ผลลัพธ์เป็นการศึกษา ไม่ใช่คำแนะนำลงทุนเฉพาะบุคคล
